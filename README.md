# ShutterBox – firmware

Firmware compilati di **ShutterBox**: controllo di 4 tapparelle con la scheda Waveshare
ESP32-S3-POE-ETH-8DI-8RO, integrato con Home Assistant (MQTT o API ESPHome).

Questo repository contiene solo i file per l'aggiornamento: le schede scaricano da qui
`manifest.json` e `firmware/ShutterBox-X.Y.Z.bin` (via jsDelivr, con api.github.com di riserva).

Nessuna versione pubblicata ancora: la prima arriverà con l'aggiornamento via rete (fase 6).
